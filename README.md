# BLM22325 – Homework 1: Multivariate Linear Regression from Scratch

## Project Description (English)
This project was prepared as Homework #1 for the BLM22325 – Machine Learning course. The aim of this assignment is to implement a multivariate linear regression model from scratch without using any ready-made machine learning libraries.

## Methods Used
- Multivariate Linear Regression
- Gradient Descent
- Mean Squared Error (Cost Function)
- Feature Normalization

## Technologies
- **Language:** Python
- **Environment:** Jupyter Notebook
- **Libraries:** NumPy, Matplotlib  
- **Note:** No libraries such as scikit-learn or pandas were used.

## Implementation Steps
- The dataset was loaded and prepared for training.
- A multivariate linear regression model was implemented from scratch.
- The model was trained using **5 different iteration values**, and cost values were stored.
- Cost vs. iteration graphs were plotted.
- The best iteration value was selected and the model was retrained using **3 different learning rates**.
- The configuration with the lowest cost was evaluated using **2 different normalization methods**.

## Files
- `Multivariate Linear Regression.ipynb` – Jupyter Notebook containing the full implementation
- `*.csv` – Dataset file (if provided separately)
